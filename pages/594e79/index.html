应用程序进程启动过程

需要注意的是这里的应用程序进程不是指应用程序

# 应用程序进程简介

要想启动一个应用程序就需要保证这个应用程序所需要的应用程序进程已经启动。AMS会在启动应用的时候检查需要的应用程序进程是否存在，不存在就会请求zygote进程启动所需要的应用程序进程。

在前面，我们知道zygote的java框架层会创建一个server端的socket，这个socket就是用来等待AMS请求zygote来创建新的应用程序进程。zygote进程通过fock自身创建应用程序进程，这样应用程序进程就会获得zygote进程在启动时创建的虚拟机实例。

除此之外，应用进程还创建了binder线程池和消息循环，这样运行在应用进程中的应用程序就可以很方便地使用binder进行进程间的用心以及消息处理了。

# 应用进程启动过程

大致分为两个部分，一是AMS发送启动应用程序请求；二是zygote接收请求并创建应用进程

当AMS发送请求的时候，也就是我们想要启动这个应用的同时。由此看来，AMS则是管理应用的生命周期。

 public static final ProcessStartResult start(final String processClass,
                                  final String niceName,
                                  int uid, int gid, int[] gids,
                                  int debugFlags, int mountExternal,
                                  int targetSdkVersion,
                                  String seInfo,
                                  String abi,
                                  String instructionSet,
                                  String appDataDir,
                                  String invokeWith,
                                  String[] zygoteArgs) {
        return zygoteProcess.start(processClass, niceName, uid, gid, gids,
                    debugFlags, mountExternal, targetSdkVersion, seInfo,
                    abi, instructionSet, appDataDir, invokeWith, zygoteArgs);
}
