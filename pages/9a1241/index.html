# 运行程序

  • 命令行运行

这种本质上就是用shell去执行这个文件，因此有两种方式

./filename.sh
1
/bin/sh filename.sh
1

因为./filename的运行默认就是用bash shell，因此这两种命令等价

需要有一个前提，就是该文件有x执行权限，如果没有，使用下面命令添加权限

chmod +x ./filename.sh
1
  • 后台运行
nohup command >out.file 2>&1 &
1

command是需要运行的命令，nohup表示不挂断运行，最后一个&表示后台运行；这个命令表示后端不挂端运行command，讲标准输出“1”和错误输出“2”合并输出到out.file文件中。后面的输出其实可以不要。

比如，这里以运行springboot项目为例子：

nohup java -jar 你的jar包名 &
1
  • 服务方式运行
systemctl start mysql
1

这种不可强求，是服务则可以使用服务方式去运行，比如mysql

# 查看端口

查看其他主机的端口能够ping通： telnet IP地址 22

查看自己主机上的端口处于监听状态：netstat -tuln | grep xxx

查看某个端口是否被占用:sudo lsof -i :端口号

# 防火墙管理

开放所有的端口:

# 查看状态
sudo ufw status

# 停用防火墙
sudo ufw disable

# 开放所有的TCP和UDP端口
sudo ufw allow proto tcp from any to any port 1:65535
sudo ufw allow proto udp from any to any port 1:65535

# 重启防火墙
sudo ufw enable

# 验证防火墙状态
sudo ufw status

# 查看端口是否开放
netstat -tuln

# 此外，还要第二个防火墙，firewall

# 安装防火墙
sudo apt-get install firewall

# 开启防火墙
sudo systemctl enable firewall
sudo systemctl start firewall

# 开放所有端口
sudo firewall-cmd --zone=public --add-port=1-65535/tcp --permanent
sudo firewall-cmd --zone=public --add-port=1-65535/udp --permanent

# 重启防火墙
root@ubuntu:~# systemctl list-units --type=service --state=running | grep firewall
  firewalld.service           loaded active running firewalld - dynamic firewall daemon                             
root@ubuntu:~# sudo systemctl restart firewalld.service
root@ubuntu:~# 

# 确认防火墙状态
root@ubuntu:~# sudo firewall-cmd --state
running
