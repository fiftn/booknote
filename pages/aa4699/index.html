# 自定义view

# 基础知识

主要是三个方法的掌握和三个构造函数、一个初始化函数。画笔的初始化在init()函数中。

对一个view进行测量大小等则在onMeasure()函数中，一些画布中的固定的东西在onLayout()函数中，绘制在onDraw()，详细介绍：

自定义View的三个方法：

  • Measure阶段：

用作View或ViewGroup尺寸的测量，父容器会对子view施加约束，View的尺寸由自身设置的大小（LayoutParams），和ViewGroup期望的大小（MeasureSpec）共同决定，MeasureSpec里面包含两个要素：测量模式和大小信息。

  • layout阶段：

一般自定义ViewGroup才会对其进行重写，以便于对所有子View进行自定义排列，以确定每个View显示的位置。

  • draw阶段：

真正对视图进行绘制，使用Canvas的API做，去绘制扇形、圆形、点、线、矩阵、图片、文本等。其可能会被频繁刷新调用，不可做耗时操作，提高代码执行效率。

# 自定义view写法：

1、需要对外提供的可定制化样式，例如填充色、圆角弧度、文字的大小样式内容等等，并在attrs.xml中做属性定义。

2、继承View或ViewGroup创建自定义view类，在构造方法中使用TypedArray获取第一步在xml中设置的值。

3、重写onMeasure、onLayout（自定义ViewGroup重写）、onDraw方法三大方法

4、对外提供API方便外界对其进行调用修改。

5、使用com.xx.xx全路径的形式对定义的View在xml中进行使用，定制化内容通过app:xx域空间设置进去.

# 自定义view三种：
  • 组合控件，大多是继承LinearLayout，比如第三章的ui中，就实现 了一个自定义的组件控件
  • 自绘控件，继承View，绘制一些高难度的东西
  • 继承控件，继承已有的控件，开发新特性

public boolean dispatchTouchEvent(MotionEvent ev) {

    	onUserInteraction();
    }
    if (getWindow().superDispatchTouchEvent(ev)) {

    }
    return onTouchEvent(ev);

# 基本介绍

属性动画主要由三个类在作用，valueAnimator类则是最原始的属性动画作用类，这个类只对数据进行处理，我们必须监听由 ValueAnimator 计算的值的更新情况，并使用您自己的逻辑修改要添加动画效果的对象。objectAnimator类则是用的比较多的，其函数api可以关联到控件以及控件的属性，然后对其设置初始值和结束值。

# 总结

1、Android 中使用最多的是属性动画，主要是利用了 Choreographer 的原理，在每个 Vsync 信号到来时计算出当前的值；

2、卡顿或抖动问题经常出现在动画过程中，所以要通过动画时长确定卡顿的点，避免分析点出错；

3、动画在每一帧都会执行，要尽量避免出现耗时操作，比如动画的对象太多或者修改的属性太多，同时应用的主线程也要避免出现耗时操作；
