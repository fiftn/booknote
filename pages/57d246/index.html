# 知识储备

光猫和路由器的作用？

简单来说，路由器主要是局域网里的神，光猫则是将光信号转为电信号。但是，目前绝大多数的光猫也自带了轻微的路由功能，并且也能开wifi，因此，大多数情况下，我们只需要一个光猫即可。

联通的光猫的默认管理员的登录网址：192.168.1.1/cu.html ，并且默认的账号和密码都是 CUAdmin

路由器在计算机网络中扮演着重要的角色，其主要作用包括以下几个方面：

路由功能：路由器通过查看各个数据包头部的目标 IP 地址，并根据预先设定的路由规则决定下一跳，将数据包从源地址传送到目标地址。它能够实现不同网络之间的数据传输和互联，并提供最佳路径选择，实现网络的连接与通信。

分配 IP 地址：路由器可以作为 DHCP（动态主机配置协议）服务器，为连接到网络中的设备分配 IP 地址和其他配置信息，以确保网络中的每个设备都有唯一的标识，并能够正确地进行通信。

网络安全：路由器在网络中具有防火墙功能。它可以筛选和阻挡来自互联网的不良流量和恶意攻击，提供网络安全防护，保护内部网络中的设备和数据安全。

网络连接共享：通过路由器，多个设备可以共享一个公共 IP 地址，实现多设备同时互联网访问。路由器还支持端口转发和网络地址转换（NAT）等功能，使得多个设备可以同时连接到互联网，并进行数据传输与通信。

无线局域网（WLAN）支持：大多数现代路由器都具备无线网络功能，可以通过 Wi-Fi 连接提供无线互联网访问和覆盖范围扩展的能力。

总而言之，路由器在计算机网络中起到了路由、分配 IP 地址、网络安全、连接共享和无线网络支持等重要作用，是实现网络连接和通信的关键设备之一。

光猫（光纤猫，光学网络终端设备）是一种专用于光纤接入的设备，

其主要作用是将光纤信号转换为电信号，提供高速的光纤接入服务。以下是光猫的主要作用：

光纤信号转换：光猫接收光纤传输的光信号，并将其转换为计算机或其他网络设备可以理解的电信号。这样，它能够实现将光纤信号传输至家庭或企业内部的各个设备。

接入提供商连接：光猫是用户与网络服务提供商（如电信运营商）连接的节点。它作为连接用户和供应商网络之间的桥梁，在用户端提供光纤接入以及对供应商网络的接入。

高速互联网接入：光猫通过光纤线路提供高速的互联网接入速度，比传统的铜线接入方式更快速、稳定。

分发网络连接：光猫通常配备多个以太网端口，可以将网络连接分发给家庭或企业内部的各个设备，如计算机、智能手机、智能电视等，实现多设备同时上网。

支持其他服务：光猫通常还提供其他的功能和服务，如电话（VoIP）接入、视频监控、WiFi 网络分发等，以满足用户对多种网络服务的需求。

总之，光猫作为光纤接入技术的核心设备，主要起到将光信号转换成电信号的作用，提供高速稳定的互联网接入以及分发网络连接给内部设备的功能。
