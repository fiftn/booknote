android中的日志

# 日志系统介绍

# 格式

格式：
date time PID-TID/package priority/tag: message

例子：
2022-05-15 21:55:00.461 1224-4993/com.google.android.gms W/GCM: GCM FAILED TO INITIALIZE - missing checkin
1
2
3
4
5
  • date：日志输出时设备的日期。
  • time：日志输出时设备的时间，精确到毫秒。
  • PID：进程标识符。
  • TID：线程标识符，若进程中只存在一个线程，则PID与TID可以相同。
  • package：输出该条日志的应用包名。
  • priority：日志优先级，取值如下，优先级从低到高排列：
    • V：详细（优先级最低）
    • D：调试
    • I：信息
    • W：警告
    • E：错误
    • A：断言
  • tag：标签，用来标明日志发起者以及方便对日志进行过滤筛选
  • message：日志的主题内容

# android中的日志获取方法

# dumpstate

查看手机系统当前状态信息（包含系统构建版本、网络相关、内存的使用、cpu的使用、进程等信息）,需要root权限。

# dmesg

打印内核kernel的信息及日志,需要root权限。

# dumpsys

获取并打印获取系统各项服务信息，可以在命令后面加指定的service name(比如activity,location),如果不加则默认打印出设备中所有service的信息。

# bugreport

输出过去系统的状态，log,会打印出dmesg，dumpstate和dumpsys的输出。

# logcat（主要）

主要是四类log buffer：main、radio、system、events

  • adb logcat -v time > logcat.txt //默认是-b main -b system
  • adb logcat -v time -b main //main log
  • adb logcat -v time -b radio //radio log
  • adb logcat -v time -b system //system log
  • adb logcat -v time -b events

常用选项
-b buffer 加载一个可使用的日志缓冲区供查看，比如event和radio。默认值是main
-g 打印日志缓冲区的大小并退出
-c 清除缓冲区中的全部日志并退出（清除完后可以使用-g查看缓冲区）
-d 将缓冲区的log转存到屏幕中然后退出, 不阻塞
-t count 输出最近的count行日志, 输出完退出, 不阻塞
-B 以二进制形式输出日志内容
-s 设置输出日志的标签, 只显示该标签的日志
-f filename 将log输出到指定的文件中,默认为标准输出（stdout）
-r kbytes 按照每千字节输出日志，默认值是16，需要和-f选项一起使用
-n count 设置日志输出的最大数目，默认值是4，需要和-r选项一起使用
-v format 设置日志的输出格式,注意只能设置一项

过滤项

过滤语法：tag：priority 其中，tag为标签，priority为优先级。 可以只使用标签，而不加优先级，则会打印指定标签所有优先级的log。

adb logcat ActivityManager:I
//（1）标签为ActivityManager，且优先级大于等于I的日志；  
adb logcat MyApp:D *:S
//（2）标签为MyApp，且优先级大于等于D的日志；

# kernel时间戳小纠正

情况是我之前弄错了kernel时间戳，其实kernel里是有两个时间戳的！

总结来说，就是proc/uptime 会比 kernel日志里的时间戳 会多，多出来的时间就是系统的睡眠时间(我理解的其实就是关机的时间！)

这是因为 proc/uptime 和实时打印的内核日志使用的是不同的时钟。

/proc/uptime 文件中的时间戳表示的是系统从启动到现在经过的时间，以秒为单位。它包括了系统的运行时间，但不包括系统的睡眠时间。

而实时打印的内核日志的时间戳表示的是事件发生的时间，通常以系统启动后的纳秒数进行计算。它包括了系统的运行时间和睡眠时间。

因此，这两个时间戳之间会有一些差异，尤其是在系统处于睡眠状态时。所以，在读取 /proc/uptime 的时间和实时打印的内核日志的时间戳之间存在差异是正常的情况。

我们经常看trace，更需要强调的是，其实trace中的时间戳用的是/proc/uptime 这个时间！

# 日志级别打印等价

android源码中打印的日志，有可能是这种形式log.v()，其实就是等价于log(verbose),这个得知道。这个verbosre也就是日志的级别。

# android中添加日志方法

在framework层中添加日志的方法：

文件路径：

/frameworks/base/core/java/android/util/Slog.java

如果，我们需要在其他地方打印日志，就需要先导入这个文件：

import android.util.Slog;
1

添加日志的语句例子如下：

Slog.d(TAG, "tingjiang i have get this . type is:" + transition.mType);
1

这里的TAG不能去掉，如果你要加的地方没有TAG，定义一个，String类型变量
