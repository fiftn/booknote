# 配置字体

修改开源画图软件的字体：https://juejin.cn/post/7083788887583096839 我最开始参考的是这个教程

如果你在网页中引入了字体，发现却没有显示的时候，需要认识到，网页使用的字体是woff，而我们电脑上的字体格式是tff

后续我重新点开这个配置，发现已经失效了，所以我重新用openwrt里的插件搭建了一个本地的，却还是没解决问题

这次笔记主要记录下，搭建的过程，其中对前端的一些理解，以及修改过程；首先思考一下如何去替换这个字体？

这个是开源项目，我用的是openwrt插件一键搭建的，那么其是使用的docker；所以就需要知道，其实就是在其中找到这个项目的前端docker（如果项目结构是分开的话），接着，前端页面一般都是部署在nginx,那就去对应的目录下找index，然后修改配置即可（这一步我们可以参考网上教程）

# 设置跨域

配置其实很简单，这里记录一下，防止忘记：

<VirtualHost *:80>
    Header set Access-Control-Allow-Origin "*" # 设置跨域
    ServerAdmin webmaster@example.com
    DocumentRoot "/www/wwwroot/jiangkk.top"
    .....
