# vscode makedown md代码片段不生效

我们在代码中配置完成后比如：

	"非常重要": {
        "prefix": "imp",
        "body": "<mark style=\"background: #ee3b3b\">$0</mark>",
        "description": "标记为非常重要"
    },
    "标题块": {
        "prefix": "titleblock",
        "body": "<mark style=\"background: #009acd\">$0</mark>",
        "description": "标记为标题块"
    },
    "突出显示": {
        "prefix": "highlight",
        "body": "<mark>$0</mark>",
        "description": "突出显示文本"
    },
    "自我总结": {
        "prefix": "summary",
        "body": "<mark style=\"background: #66cd00\">$0</mark>",
        "description": "标记为自我总结"
    },
    "抛出疑问": {
        "prefix": "question",
        "body": "<mark style=\"background: #9a32cd\">$0</mark>",
        "description": "标记为抛出疑问"
    }
