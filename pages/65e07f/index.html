# 显示

# ls

主要看ls显示出来的文件的含义，其中文件类型有：

  • d：表示目录
  • -：表示文件
  • l：表示连结挡
  • b：表示装置文件里可供储存的接口设备
  • c：表示装置文件里串行端口设备，比如键盘、鼠标
  • s：表示一个套接字文件，用于不同进程之间的通信

# cat more less

  • cat：用于显示文件的内容
  • more：显示文件，空格显示下一页数据，回车显示下一行数据
  • less：pgup、pgdn进行上下翻页

# tail

  • -n：显示文件尾部n行数据
  • -f：动态显示文件尾部数据，即程序运行的日志可以动态查看

# 查找

# find

find [路径] [条件] 文件名 ：用于查找符合条件的文件

  • -name：匹配文件名
  • -perm：匹配文件权限
  • -type：匹配文件类型
  • -size：匹配文件大小
  • ......
# 查找文件目录及其子文件下的所有html文件，并根据查找的内容替换指定的内容
# 这两句代码分别将user-select: none; 替换为user-select: auto; 因为要递归其子目录，所以需要find命令来搭配，不然仅仅sed就足够了
find /path/to/directory -type f -name "*.html" -exec sed -i 's/user-select: none;/user-select: auto;/g' {} +
find /path/to/directory -type f -name "*.html" -exec sed -i 's/user-select:none/user-select:auto/g' {} +
# 这两段代码是给极客的html中禁止鼠标操作改成可以操作

# grep

grep [参数] 文件名 : 用于查找文件里符合条件的字符串

  • -b 显示匹配行距文件头部的偏移量
  • -c 只显示匹配的行数
  • -E 支持扩展正则表达式
  • -F 匹配固定字符串的内容
  • -h 搜索多文件时不显示文件名
  • -i 忽略关键词大小写
  • -l 只显示符合匹配条件的文件名
  • -n 显示所有匹配行及其行号
  • -o 显示匹配词距文件头部的偏移量
  • -q 静默执行模式
  • -r 递归搜索模式
  • -s 不显示没有匹配文本的错误信息
  • -v 显示不包含匹配文本的所有行
  • -w 精准匹配整词 -
  • x 精准匹配整行
# 在当前文档下查找wps关键字
grep -rn "wps" ./文档

# 在当前文档下递归搜索两个关键字
grep -e "Unmount all"  -e "Restarting syst" . -nr

# 在当前文件下递归搜索指定文件名下的关键字
find . -name "bootprof" -exec grep -rn "preloader" {} +

# 编辑

# sed

sed命令来自英文词组“stream editor”的缩写，其功能是用于利用语法/脚本对文本文件进行批量的编辑操作

sed [参数] 文件名：对指定的文件进行各种编辑操作

  • -e 使用指定脚本来处理输入的文本文件
  • -f 使用指定脚本文件处理输入的文本文件
  • -h 显示帮助信息
  • -i 直接修改文件内容，而不输出到终端
  • -n 仅显示脚本处理后的结果
  • -r 支持扩展正则表达式
  • -V 显示版本信息
# 将指定的html文件，其中的 user-select: none; 内容替换为 user-select: auto;
sed -i 's/user-select: none;/user-select: auto;/g' filename.html

# 替换指定文件中的关键字为大写模式
sed 's/root/ROOT/g' File.cfg

# 读取指定文件，删除所有带有某个关键词的行
sed '/root/d' File.cfg

# 其使用的是正则表达式的方式，因此熟练使用正则很重要

# 操作

# > 和 >>

  • cat a.txt > b.txt：将输出定向到b中
  • cat a.txt >> b.txt：将输出追加到b中

# rm

  • -d：删除空目录
  • -r：递归删除
  • -f：强制删除，不询问用户

# cp、mv

  • cp a.txt b.txt：将a文件复制为b文件
  • cp a.txt ../：将a文件复制到上一级目录

# 运行程序

# 第一种方式，直接运行
# 运行这个程序，执行条件是这个文件有x执行权限，这是linux执行程序最常用的一种方式，通过shell在交互命令行里运行
./filename 

# 第二种方式，后台运行
# •这里面，“1”表示文件描 述符 1，表示标准输出，“2”表示文件描述符 2，意思是标准错误输出，“2>&1”表示 标准输出和错误输出合并了。合并到哪里去呢？到 out.file 里。
nohup command >out.file 2>&1 &

# 关闭后台运行的进程
# 这里解释下awk工具:，这里的 awk '{print $2}'是指第二列的内容，是运 行的程序 ID。我们可以通过 xargs 传递给 kill -9，也就是发给这个运行的程序一个信号， 让它关闭。如果你已经知道运行的程序 ID，可以直接使用 kill 关闭运行的程序
ps -ef |grep 关键字 |awk '{print $2}'|xargs kill -9
# 我更喜欢的常用方式：
ps -ef | grep 关键字 ——》肉眼找出要查杀的进程pid，然后kill -9 pid 手动查杀

# 第三种方式，服务模式运行
systemctl start mysql #启动
systemctl stop mysql #停止
systemctl enable mysql #设置开机启动

# 回滚依赖包
# yum命令安装软件包会同时安装需要的依赖包，但yum remove却只卸载这个文件包本身，如果需要删除安装时附加的依赖包，则可以使用yum history的相关操作实现回滚:

# 1.查看需要卸载的软件包信息，特别是查看事务id
yum history list
# 2.回滚重新安装
yum history redo 事务id
# 2.或者回滚进行卸载，包括安装附加的依赖
yum history undo 事务id

tar -xvzf xxx: 解压xxx文件到当前目录下(.tar.gz 或 .tgz 压缩文件)

# ln

# 软连接配置环境
# 软硬区别：软链接相当于Windows系统中的快捷方式文件，原始文件被移动或删除后，软链接文件也将无法使用，而硬链接则是通过将文件的inode属性块进行了复制 ，因此把原始文件移动或删除后，硬链接文件依然可以使用

cd /usr/bin #进入bin目录
ln -s /usr/local/node/bin/node node #创建软链接，表示/usr/local/node/bin/node 创建快捷方式到当前目录下，并且命名为node
ln -s /usr/local/node/bin/npm npm #-s表示链接
