递归和回溯：本质上区别则是回溯会用到递归回来时候，这么说太抽象；递归只会在正向一往无前或者回来的时候一往无前找到结果，比如正向二分查找，当我达到临界点的时候，我已经找到了我想要的值，那么 逆向其实也很好理解，比如求解二叉树的最大深度的时候：

public int findMaxHeight (TreeNode root) {

递推和动态规划的区别

动态规划本质上是递推的子集，但是这里递推只代表狭义上的解题，当子问题不重叠的时候，可以使用简单的递推来求解，当子问题重叠的时候则需要动态规划结合数组来求解

如何理解子问题重叠？

比如递推求解斐波那契数列的问题，f(n) = f(n-1) + f(n-2)，这时候递推其实子问题是不重叠的，也就是我求比如f(9)的时候，只需要知道前两个数字即可

但是，比如数字三角形这题，每一个子问题的状态都需要其子问题来求解，这时候就需要一个动态数组每次存储最优解

# 位运算

位与（AND）：用符号 “&” 表示，对两个操作数的对应位进行与操作，只有在两个位都为 1 时结果才为 1，否则为 0。

位或（OR）：用符号 “|” 表示，对两个操作数的对应位进行或操作，只要其中任意一位为 1，结果就为 1。

位异或（XOR）：用符号 “^” 表示，对两个操作数的对应位进行异或操作，当两个位不相同时结果为 1，否则为 0。

位取反（NOT）：用符号 “~” 表示，对操作数的每一位进行取反操作，即 1 变为 0，0 变为 1。

左移（<<）：将操作数的二进制位向左移动指定的位数，右侧用 0 填充。

右移（>>）：将操作数的二进制位向右移动指定的位数，左侧用符号位（正数用 0 填充，负数用 1 填充）或者 0 填充。

# 找出数组中元素两两相同，只出现一次的两个元素

使用异或位运算，思路如下：

其实就是两两抵消的思路，两个相同的元素异或相当于不存在，这里要找出两个只出现一次的元素，就需要找到他们某一位不相同的数字，

比如4 和 5， 那就是 1000 和 1001，也就是最后一位不相同，然后只需要对原数组进行分组，分别异或，就可以找到这两个数字了

找到这两位数字的不同也很简单，先异或一遍，得到两个数的异或结果，其中某一位等于1，就是该位不相同了

public static int[] findTwoSingleNumbers(int[] nums) {
        // 第一次异或运算，找到两个只出现一次的元素的异或值
        int xorResult = 0;
        for (int num : nums) {
            xorResult ^= num;
        }

        // 找到异或结果中为1的任意一位
        int bit = 1;
        while ((xorResult & bit) == 0) {
            bit <<= 1;
        }

        // 分组并进行异或运算
        int[] result = new int[2];
        for (int num : nums) {
            if ((num & bit) == 0) {
                result[0] ^= num;
            } else {
                result[1] ^= num;
            }
        }

        return result;
    }

# 递推和递归

递推：递推算法是一种通过基本情况和已知结果来计算后续值的方法。它是通过应用一系列规则或公式，从已知的初始条件推导出更大的问题的解。递推算法通常是通过迭代的方式，逐步推进，直到达到目标或满足某个终止条件。

递归：递归是一种通过将问题划分为更小的子问题，并通过递归地解决子问题来解决整个问题的方法。在搜索问题中，递归算法可以通过将搜索空间划分为更小的子空间，并在每个子空间上递归地进行搜索，从而找到目标元素或满足特定条件的元素。

# 递归

基础的递归遍历是一种搜索算法，需要区别于dfs的是，递归遍历应用于单向路，回来的节点只会被访问一次，但是dfs中对当前节点的所有可能进行访问，并不是单向的。

举例理解：递归遍历可以应用于链表、数组、二叉树，dfs应用于图的遍历。前者都是访问当前节点，回头时，当前节点只被访问一次；dfs会访问多次，因此需要标记一下

递归遍历链表：

    // 递归遍历下一个节点

}

private void dfs(/* 当前节点 */, boolean[] visited, /* 其他参数 */) {
    // 停止条件

}

# 基本树概念

树的术语：

  • 根节点（Root）：树的顶部节点，没有父节点的节点。
  • 父节点（Parent）：一个节点的直接上级节点。
  • 子节点（Child）：一个节点的直接下级节点。
  • 兄弟节点（Sibling）：具有相同父节点的节点。
  • 叶节点（Leaf）：也称为终端节点，没有子节点的节点。
  • 分支节点（Internal Node）：至少有一个子节点的节点。
  • 子树（Subtree）：由一个节点及其所有子节点和后代节点组成的树。
  • 祖先节点（Ancestor）：在某个节点向上的路径上的所有节点。
  • 后代节点（Descendant）：在某个节点向下的路径上的所有节点。
  • 层级（Level）：根节点为第一层，其子节点为第二层，依此类推。
  • 深度（Depth）：某个节点到根节点的层数。
  • 高度（Height）：树中最深层的节点的深度。

二叉树性质：

  • 性质1：非空二叉树上的叶子节点数等于双分支节点数加1
  • 性质2：非空二叉树的第i层上最多有2^(i-1)个结点
  • 性质3：高度位h的二叉树最多有2^h-1个结点

下标规则：双亲的结点下标为 i/2 左孩子的小标为2i 右孩子的下标为2i+1

# 红黑树

红黑树是一种自平衡的二叉查找树，是计算机科学中用到的一种数据结构，它是在1972年由Rudolf Bayer发明的，当时被称之为平衡二叉B树，后来，在1978年被

Leoj.Guibas和Robert Sedgewick修改为如今的"红黑树"。它是一种特殊的二叉查找树，红黑树的每一个节点上都有存储位表示节点的颜色，可以是红或者黑；

红黑树不是高度平衡的，它的平衡是通过"红黑树的特性"进行实现的；

红黑树的特性：

  1. 每一个节点或是红色的，或者是黑色的。
  2. 根节点必须是黑色

# 基本图概念

  • 节点（Node）：也称为顶点（Vertex），是图中的一个个独立的实体。节点可以具有一个或多个属性，用于描述节点的特征。

  • 边（Edge）：表示节点之间的连接关系。边可以是有向的（有箭头的），也可以是无向的（没有箭头的）。有向边从一个节点指向另一个节点，无向边没有方向性，表示两个节点之间的双向连接。

  • 权重（Weight）：适用于带权图，在边上附加的数值，表示节点之间的关联程度或路径的成本。可以是整数、实数或其他类型的值。

路径被定义为从一个顶点到另一个顶点的一系列连续边，例如上图中【北京】到【上海】有多条路径

北京 - 上海

北京 - 武汉 - 上海

路径长度

不考虑权重，长度就是边的数量

考虑权重，一般就是权重累加

  • 路径（Path）：由边连接的一系列节点组成的序列。路径可以是简单路径，即不重复经过节点的路径，也可以是环路，即起点和终点相同的路径。

  • 连通性（Connectivity）：描述图中节点之间是否存在通路。如果图中的任意两个节点之间都存在路径，则图被称为连通图。否则，图被称为非连通图。

  • 度数（Degree）：节点的度数是指与该节点直接相连的边的数量。对于有向图，分为入度（In-degree）表示指向节点的边的数量，和出度（Out-degree）表示从节点发出的边的数量。

例如上图中

D 顶点度数为 4

有向图中，细分为入度和出度，

A (2 out / 0 in)

B、C、E (1 out / 1 in)

D (2 out / 2 in)

F (0 out / 2 in)

  • 子图（Subgraph）：图中的一个子集，由一些节点和它们之间的边组成。

  • 有向无环图（Directed Acyclic Graph，DAG）：一个有向图，其中不存在循环路径。在计算机科学中，DAG常用于表示任务依赖关系、编译顺序等。

  • 最短路径（Shortest Path）：在图中寻找两个节点之间距离最短的路径。最短路径算法常用于路由规划、网络优化等领域。

  • 最小生成树（Minimum Spanning Tree，MST）：在连通图中，通过选择边的子集构建一棵树，使得所有的节点都被连接，并且边的权重之和最小。最小生成树在网络设计、电缆布线等领域有应用。

  • 连通图（Connected Graph）：连通图是指在图中，任意两个节点之间都存在至少一条路径的图。也就是说，对于连通图中的任意两个节点，它们之间存在一条路径可以通过边相连。连通图可以是有向的或无向的。

  • 连通分量（Connected Components）：连通分量是一个概念，用来描述一个图中具有相互连接的节点子集。简单理解就是子图，连通图的连通分量就是自己。
