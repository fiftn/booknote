模块 产物 说明
framework .jar Android 框架的库文件，通常放在 out/target/product/target-devices/system/framework 下。替换此文件后重启设备或模拟器即可生效。
system .img 整个系统的镜像文件，位于 out/target/product/target-devices/system.img。通过 adb push 或更新镜像进行刷机使更改生效。
apps .apk 应用程序包，位于 out/target/product/target-devices/system/app 或 system/priv-app 下。可以通过 adb install 或替换后重启设备使更改生效。
boot boot.img 引导镜像，位于 out/target/product/target-devices/boot.img。替换后需要重新启动设备以应用更改。
vendor .img 与硬件相关的图像，通常位于 out/target/product/target-devices/vendor.img。需要通过刷机或重启设备使更改生效。
recovery recovery.img 恢复模式镜像，位于 out/target/product/target-devices/recovery.img。替换后重启设备使更改生效。
lib .so 动态库，位于 out/target/product/target-devices/system/lib 或 system/lib64。替换后需要重启设备或应用才能生效。
etc 配置文件 位于 out/target/product/target-devices/system/etc。修改后重启设备或重新加载配置即可生效。
