# 攻略

  • 阅读习惯，我一般会ListNode cur = head;表示会移动的节点，代替head节点，最后返回head节点

  • 可以 ListNode preHead = new ListNode(-1); preHead.next = head; 声明head的前置节点

使用到的场景，当我们解链表题时，想获取上一个节点，还要搞一个pre节点在循环中标记时，这个时候不妨直接定位声明前置节点，这样当前节点就是前置节点，可以省去一些判空的麻烦事；例子可以看双指针的应用场景

  • 使用前置节点，便于后续找到节点后移动该节点

# 链表中去重&遍历

农场里有一群牛，每头牛都有一个独特的编号，编号由一个整数表示，整数范围是[0, 200]。牛群中的牛用单链表表示，链表已经按照非降序排列。

因为一些事故，导致一头牛可能多次出现在链表中。给你一个链表的头 head，删除链表中所有重复的编号，只留下所有牛的不重复编号。返回已排序的链表。

示例1

输入： {1,2,2,3,3,4,5,5}

返回值： {1,2,3,4,5}

备注： 链表中节点数目在范围 [0, 1000] 内； 0 <= Node.val <= 200；

思路：直接遍历即可，如果遇到当前节点和下一个节点值一致，从当前节点遍历直到下一个节点值不一致即可

public ListNode deleteDuplicates (ListNode head) {
    // write code here
    ListNode cur = head;
    ListNode pre = head;
    while (cur != null && cur.next != null){
        if(cur.val == cur.next.val) {
            pre = cur; //定位当前节点
            while (true) {
                if (cur.next == null || cur.val < cur.next.val) {
                    pre.next = cur.next; //确定下一个赋值节点
                    break;
                }
                cur = cur.next;
            }
        }
        cur = cur.next;
    }
    return head;
}

# 移动链表倒数第n个节点&双指针

农场里有一群牛，每头牛都有一个编号，编号由一个整数表示，整数范围是[0, 100]。牛群中的牛用单链表表示。

现在，农场主想要调整牛群的顺序。给你一个链表，将链表中的倒数第 n 个结点移到链表的末尾，并且返回调整后的链表的头结点。

示例1

输入： {1,2,3,4,5},2

返回值：{1,2,3,5,4}

备注

链表中结点的数目为 sz； 1 <= sz <= 30； 0 <= Node.val <= 100； 1 <= n <= sz；

思路：思路很简单找到这个节点，然后放到最后就行了，入门级，但是这里有一个效率问题，就是需要遍历两次(因为我们并不知道链表长度)；利用双指针的话，就只需要遍历一遍即可

双指针思想：我们用两个指针遍历即可，指针p1右移n，p2不动，当p1到尾部的时候，p2则指向倒数n个；但是这里有一个问题，思考下，当slow指针指向了要移动的节点的时候，却发现上一个节点还没拿到，如果遍历的时候去标记，会遇到很多判空的麻烦， 倒不如直接让slow指向上一个节点，省去很多麻烦，也很好实现，构造虚拟节点即可：ListNode preHead = new ListNode(-1); preHead.next = head;

public ListNode moveNthToEnd_2 (ListNode head, int n) {
        // write code here
        if (n == 1) {
            return head;
        }

        ListNode preHead = new ListNode(-1);
        preHead.next = head;
        ListNode fast = preHead;
        ListNode slow = preHead;

        // 将fast指针移动到链表的第n个节点
        for (int i = 0; i < n; i++) {
            fast = fast.next;
        }

        // 同时移动fast和slow指针，直到fast指针达到链表末尾
        while (fast.next != null) {
            fast = fast.next;
            slow = slow.next;
        }

        ListNode target = slow.next;
        slow.next = slow.next.next;
        fast.next = target;
		target.next = null;

        return preHead.next;
    }

# 链表每k组翻转

农场里有一群牛，每头牛都有一个编号，编号由一个整数表示，整数范围是[0, 1000]。牛群中的牛用单链表表示。

现在，农场主想要重新分组牛群。给定一个单链表的头指针 head 和一个整数 k，每 k 个节点一组进行翻转，请你返回修改后的牛群链表。

k 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 k 的整数倍，那么请将最后剩余的节点保持原有顺序

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

示例1

输入： {1,2,3,4,5},2

返回值：{2,1,4,3,5}

备注：

链表中的节点数目为 n； 1 <= k <= n <= 5000； 0 <= Node.val <= 10000；

思路：既然是翻转，数据倒置，那肯定是用栈来做；正常的模拟，每k组加入stack中，然后取出来，放到新链表中；最后一组不足，判断i和k即可，然后拼接之前标记的节点

public ListNode reverseKGroup (ListNode head, int k) {
        // write code here
        int i;
        ListNode cur = head;
        ListNode tmp = new ListNode(-1);
        ListNode hhead = tmp;
        ListNode flag = null;//标记
        Stack<Integer> stack = new Stack<>();
        while (cur != null) {
            flag = cur;//标记
            for (i = 0; i < k && cur != null; i++) {
                stack.push(cur.val);
                cur = cur.next;
            }
            if(i != k) //最后不足一组，栈不足k个，并且不用翻转，直接退出
                break;
            for (i = 0; i < k; i++) {
                ListNode p = new ListNode(stack.pop());
                p.next = null;
                tmp.next = p;
                tmp = p;
            }
        }
        //处理剩下的栈，如果为空，则刚好；不为空，则不足，顺序拼接，利用上之前的flag
        if (!stack.isEmpty())
            tmp.next = flag;
        return hhead.next;
    }

# 链表区间翻转

农场里有一群牛，每头牛都有一个编号，编号由一个整数表示，整数范围是[-500, 500]。牛群中的牛用单链表表示。 现在，农场主想要改变牛群的排列顺序。给定一个单链表的头指针 head 和两个整数 left 和 right，其中 left <= right。请你反转从位置 left 到位置 right 的链表节点，返回 反转后的牛群链表。

示例1

输入：{1,2,3,4,5},2,4

返回值：{1,4,3,2,5}

备注

链表中节点数目为 n ； 1 <= n <= 1000 ； -500 <= Node.val <= 500 ； 1 <= left <= right <= n ；

思路：搞一个新链表，左子链表顺序拼接，中子链表用栈取出数据逆序拼接，后子链表直接拼接

学习：这题让我理解了一个链表的本质，一开始左子链表我也是直接拼接，后面才意识到，l找到左子链表右边界的时候，l前面的节点都丢了

链表的本质：比如给你一个head头节点，代表两个信息：1.head代表这个链表，后面有很多节点，未知 ；2.head是这个链表的头，head.next = null，那么这个链表也就“找不到了”

public ListNode reverseBetween (ListNode head, int left, int right) {
        // write code here
        ListNode tmp = head;
        ListNode l = new ListNode(-1); //左子链表，随tmp移动的节点，定义左子链表右边界
        ListNode ll = l;//左子链表头节点，
        ListNode mid = new ListNode(-1);//中子链表，需要翻转的子链表，随tmp移动节点，定义中子链表右边界
        ListNode mmid =mid;//中子链表头节点，表示：[-1 -> 节点1]
        Stack<Integer> stack = new Stack<>();
        while (head !=null){
            for(int i=1;i<left;i++){
                ListNode p = new ListNode(tmp.val);
                p.next =null;
                l.next = p;
                l = p;
                tmp = tmp.next;
            }

            for (int i=0;i<right - left +1;i++){
                stack.push(tmp.val);
                tmp = tmp.next;
            }

            for (int i=0;i<right -left +1;i++){
                ListNode p = new ListNode(stack.pop());
                p.next =null;
                mid.next = p;
                mid = p;
            }
            break;
        }
        l.next = mmid.next;//左和中连接
        mid.next = tmp;//中和右连接
        return ll.next;
    }

# 链表合并

农场里有两群牛，每群牛都有一定的能量值。能量值由一个整数表示，整数范围是[-100, 100]。每群牛的能量值已经按照非递增顺序排列，并存储在链表中。

现在，你需要将这两群牛的能量值合并为一个新的非递增链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

示例：

输入：{4, 2, 1},{4, 3, 1}

输出：{4,4,3,2,1,1}

备注： 两个链表的节点数目范围是 [0, 50] ； -100 <= Node.val <= 100 ； l1 和 l2 均按非递增顺序排列 ；

思路：简单链表合并，放上来也就觉得经典，不多说了

public ListNode mergeEnergyValues (ListNode l1, ListNode l2) {
    // write code here
    ListNode l3 = new ListNode(-1);
    ListNode cur = l3;
    ListNode p =null;
    while (l1 != null && l2 != null){
        if(l1.val >= l2.val){
            p = new ListNode(l1.val);
            l1 = l1.next;
        }else{
            p =new ListNode(l2.val);
            l2 = l2.next;
        }
        p.next =null;
        cur.next =p;
        cur=p;
    }
    cur.next = l1!=null ? l1 :l2;
    return l3.next;
}

# 链表相加&模拟大整数加法

农场里有两群牛，每群牛都有一定的能量值。能量值由一个非负整数表示，且每头牛的能量值只有一位数字。能量值按照逆序的方式存储在链表中，即链表的第一个节点表示个位，第二个节点表示十位，以此类推。

现在，你需要将这两群牛的能量值相加，然后以相同的逆序形式返回表示和的链表。

注意：除了数字0之外，这两个数都不会以0开头。

示例：

输入：{9, 8, 7, 6, 5},{ 1, 1, 1, 1, 1}

输出：{0,0,9,7,6}

说明：56789+11111=67900

备注：

每个链表中的节点数在范围 [1, 500] 内 ； 0 <= Node.val <= 9 ；

思路：简单模拟，用链表实现大整数的加法，需要注意两个点，1.大整数存储到链表是倒序的 2.相加的时候别忘记了进位值p，当两个链表都相加完，p还在的话，也要继续处理的

public ListNode addEnergyValues (ListNode l1, ListNode l2) {
    // write code here
    ListNode l3 = new ListNode(-1);
    ListNode cur = l3;
    int p = 0;
    while (l1 != null && l2 != null) {
        ListNode tmp = new ListNode((l1.val + l2.val + p) % 10);
        tmp.next = null;
        cur.next = tmp;
        cur = tmp;
        p = (l1.val + l2.val + p) / 10;
        l1 = l1.next;
        l2 = l2.next;
    }
    //剩下的情况，l1和p 或者 l2和p，p进位值和链表不能直接拼接，因为可能会再次触发进位
    ListNode cns = l1 != null ? l1 : l2; 
    while (cns != null) {
        ListNode tmp = new ListNode((cns.val + p) % 10);
        tmp.next = null;
        cur.next = tmp;
        cur = tmp;
        p = (cns.val + p) / 10;
        cns = cns.next;
    }
    //可能还会存在进位，并且不可能大于1
    if (p == 1) {
        cur.next = new ListNode(1);
        cur.next.next = null;
    }
    return l3.next;
}

# 判断链表是否有环&双指针

农场里有一群牛，它们被组织成一个链表形式的队列。每头牛都有一个编号（每只牛编号唯一），编号范围是[-105, 105]。每头牛都有一个指针，指向它后面的一头牛。但是，有一些顽皮的牛可能会指向它们前面的某一头牛，从 而形成一个环。

现在，给你一个链表的头节点 head，判断这个牛队列中是否有环。

示例：

输入：{3,2,0,-4,2,0,-4,2,0,-4,2,0,-4,2,0,-4,2,0,-4}

输出：true

说明：这个题目出的不标准，给的链表容易让人误解，具体看我的思路分析

思路：可能有同学不理解题意，题目给的太潦草，别把给的输入看出数组，而是一个链表，举个简单例子：

1 -> 2 -> 3 -> 4 无环链表

1 -> 2 -> 3 -> 4 ->2 有环链表

那么，最简单的方法就是使用两个指针，快慢指针步长差1，遍历到底，有环，一定可以追上，在这个例子中：

快指针到4的时候，就会回去，慢指针还在路上，步长为2，兜圈子，一定可以碰到

public boolean hasCycle (ListNode head) {
    // write code here
    if (head == null || head.next == null)
        return false;
    ListNode slow = head;
    ListNode fast = head;
    while (fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow.val == fast.val)
            return true;
    }
    return false;
}

# 链表旋转&双指针

农场里有一群牛，每头牛都有一个编号，编号由一个整数表示，整数范围是[-100, 100]。牛群中的牛用单链表表示。

现在，农场主想要调整牛群的顺序。给你一个链表的头节点 head ，将链表每头牛向右移动 k 个位置。

输入：

{1,2,3,4,5,6,7,8,9},3

返回值：

{7,8,9,1,2,3,4,5,6}

思路：和移动链表的倒数第n个节点类似，主要两点，1.移动k>n，就是移动k%n的距离；2.其实向右移动k等价于右链表拼接到前面，从图中清晰看出

public ListNode rotateLeft (ListNode head, int k) {
    // write code here
    ListNode slow = new ListNode(-1);
    slow.next = head;
    ListNode fast = new ListNode(-1);
    fast.next = head;
    //拿到链表长度
    ListNode cur = head;
    int n = 0;
    while (cur != null){
        n++;
        cur = cur.next;
    }
    k = k > n ? k % n : k;
    //快指针移到n=k地方
    while (k-- !=0){
        fast = fast.next;
    }
    //一起移动到尾部
    while (fast.next != null){
        fast = fast.next;
        slow = slow.next;
    }
    fast.next = head;
    head = slow.next;
    slow.next = null;
    return head;
}

# 二叉树找最大值&递归本质

农场里有一群牛，牛群的成员分布在山坡上，形成了一个二叉树结构。每头牛都有一个高度值，表示它在山坡上的高度。请你编写一个程序，找出牛群中的最高牛。

说明：最高牛是指高度值最大的牛。

示例：

输入：{1, 2, 3, #, #, 4, 5}

输出：5

备注：

输入包含一个二叉树，表示牛群的分布。二叉树由一组整数表示，其中 # 表示空节点。节点按层序遍历的顺序给出。

二叉树节点数[1, 100]

public boolean dfs(TreeNode left,TreeNode right){

    return dfs(left.left, right.right) && dfs(left.right, right.left);
}

# 判断搜索二叉树

在一个牧场中，有很多牛。为了方便管理与查找，牧场主将牛的编号排列成一棵二叉搜索树。请你编写一个程序，给定一棵二叉树的根节点 root，判断其是否是一个有效的二叉搜索树。

输入：

{1, 2, 3}

输出：

false

思路：这里主要是将临界条件和终止条件找出来，列出所有可能的情况：

  • 如果是搜索二叉树最终会走到临界条件，返回true；如果是不是搜索二叉树，走我们的终止条件
  • 其次记住，所有条件不能锁死，你的true条件，必须是临界条件
public boolean isValidBST (TreeNode root) {
    // write code here
    /*
    临界状态： root == null
    停止递归状态： 左子树大于根节点 || 右子树小于根节点
     */
    if(root == null)
        return true;
    if(root.left !=null && root.left.val>root.val || root.right !=null && root.right.val<root.val)
        return false;
    /*
    左右子树的关系：左子树的结果和右子树的结果都是true，才是搜索二叉树
     */
    return isValidBST(root.left) && isValidBST(root.right);
}

public boolean leafSimilar(TreeNode root1, TreeNode root2) {
        Stack<Integer> stack1 = new Stack<>();
        Stack<Integer> stack2 = new Stack<>();

        pushLeftLeaves(root1, stack1);
        pushRightLeaves(root2, stack2);

        return stack1.equals(stack2);
    }

private void pushLeftLeaves(TreeNode node, Stack<Integer> stack) {
    if (node != null) {
        if (node.left == null && node.right == null) {
            stack.push(node.val);
        } else {
            pushLeftLeaves(node.left, stack);
            pushLeftLeaves(node.right, stack);
        }
    }
}

private void pushRightLeaves(TreeNode node, Stack<Integer> stack) {
    if (node != null) {
        if (node.left == null && node.right == null) {
            stack.push(node.val);
        } else {
            pushRightLeaves(node.right, stack);
            pushRightLeaves(node.left, stack);
        }
    }
}

{3, 1, 4, #, 2},2

2

public static int cnt = 0;
public static int key = 0;
public void inorder(TreeNode root,int k){
    if(root == null)
        return;
    inorder(root.left,k);
    if(++cnt == k){
        key = root.val;
    }
    inorder(root.right,k);
}
public int kthLighest (TreeNode root, int k) {
    // write code here
    inorder(root,k);
    return key;
}

# 二叉树z字排序&队列

在一个牧场中，有很多牛。为了方便管理，牧场主将牛的编号排列成一棵二叉树。现在牧场主想知道每层牛的编号。请按照从上到下，从左到右的顺序，返回每层牛的编号，但是要求每一层的遍历顺序为Z字形（即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行）。

输入：

{3, 9, 20, #, #, 15, 7}

返回值 [[3],[20,9],[15,7]]

思路：有一类题都是利用层序队列进行各种计算，比如每一层的最大值，不用z字，只需要分层排列，树的左侧视图等，关键点在于遍历过程中，判断队列的大小，就是这一层的节点个数

public int[][] ZLevelOrder (TreeNode root) {
    // write code here
    if (root == null)
        return new int[][]{};
    Queue<TreeNode> queue = new LinkedList<>();
    ArrayList<Integer[]> array = new ArrayList<>();
    queue.add(root);
    boolean flag = true;//判断标志函数
    while (queue.size() != 0) {
        ArrayList<Integer> arr = new ArrayList<>();
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            arr.add(node.val);
            //不为null，向其中添加子树
            if (node.left != null)
                queue.add(node.left);
            if (node.right != null)
                queue.add(node.right);
        }
        flag = !flag;
        if(flag)
            Collections.reverse(arr);
        array.add(arr.toArray(new Integer[] {0}));
    }
    //使用stream流 将array转为int[][]类型
    return array.stream()
            .map(row -> Arrays.stream(row).mapToInt(Integer::intValue).toArray())
            .toArray(int[][]::new);
}

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最大权值的牛的体重的数据结构。

实现 MaxCowStack 类：

MaxCowStack() 初始化堆栈对象。

void push(int id, int weight) 将编号为 id 且体重为 weight 的牛推入堆栈。

void pop() 删除堆栈顶部的元素。

int top() 获取堆栈顶部的体重。

int getMax() 获取最重一头牛的体重。

输入：

["MaxCowStack","push","push","push","getMax","pop","top","getMax"],[[],[1,2],[2,3],[3,1],[],[],[],[]]

返回值：

[-1,-1,-1,-1,3,-1,3,3]

前四个操作没有获取元素，用-1占位，并连续将三个元素加入到栈中；然后获取最大值3；弹出栈顶元素，继续用-1占位；然后获取栈顶元素3；最后获取最大值3.

public int[] max_weight_cow (String[] op, int[][] vals) {
    // write code here
    Stack<Integer> stack = new Stack<>();
    Stack<Integer> maxStack = new Stack<>();
    int[] arr = new int[op.length];
    for (int i=0;i<op.length;i++){
        arr[i] = -1;
        if(op[i].equals("MaxCowStack")){
            //创建栈
        }
        else if (op[i].equals("push")){
            stack.push(vals[i][1]);
            //维护最大栈
            if(!maxStack.isEmpty() && maxStack.peek() > vals[i][1])
                maxStack.push(maxStack.peek());
            else 
                maxStack.push(vals[i][1]);
        }
        else if(op[i].equals("pop")){
            stack.pop();
            maxStack.pop();
        }
        else if(op[i].equals("top")){
            arr[i] = stack.peek();
        }
        else 
            arr[i] = maxStack.peek();
    }
    return arr;
}
