# ai多媒体

# 1. Genspark.ai

链接: https://www.genspark.ai/
核心功能：

  • AI对话：多轮自然语言对话，复杂问题解答
  • 多媒体创作：
    • 🎨 绘画：文生图生成与编辑（积分消耗）
    • 📊 PPT：主题输入自动生成结构化幻灯片
    • 📹 视频：脚本生成/字幕翻译/配音（企业版）
  • 办公辅助：文档总结/代码编写/数据分析
    特色：

🔒 企业级中台架构，支持私有化部署

# 2. Felo.ai

链接: https://chat.felo.ai/
核心功能：

  • AI对话：长上下文记忆/角色扮演
  • 多媒体支持：
    • 🖼️ 绘画：DALL-E 3高清图生成（1024x1024等）
    • 🖥️ PPT：自动生成大纲+配图+演讲备注
    • 🎵 音乐：背景音乐生成（实验性）
      特色：

🆓 50万Tokens免费额度，支持插件扩展

# 3. AICCC

链接: https://aicccc.com/draw
核心功能：

  • AI对话：基础绘画指令交互
  • 多媒体核心：
    • ✨ 绘画：
      • DALL-E 3文生图/混图/咒语解析
      • 定制尺寸（1792x1024壁纸等）
      • ⚡积分消耗（5积分/次）
    • 🖌️ 图像编辑：描述生成/关键词优化
      局限：

❌ 无PPT/视频功能

# 4. 火山引擎

链接: https://www.volcengine.com/
核心功能：

  • AI对话：企业级大模型（豆包）/角色扮演
  • 多媒体办公：
    • 📈 PPT：营销方案/报告自动生成
    • 🎬 视频：
      • 多模态翻译（字幕/配音/口型同步）
      • 广告视频生成（企业版）
    • 🧩 绘画：通过Agent平台间接接入
      特色：

🏢 企业AI中台，支持7x24高并发任务
