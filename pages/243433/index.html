环境准备

1. linux机器安装 docker 并拉取镜像
sudo apt install docker.io
sudo docker run --name ppocr -v $PWD:/paddle --network=host -it registry.baidubce.com/paddlepaddle/paddle:2.1.3-gpu-cuda10.2-cudnn7 /bin/bash

2. 进入容器后 安装依赖
sudo docker container exec -it ppocr /bin/bash
python3 -m pip install paddlepaddle -i https://mirror.baidu.com/pypi/simple
pip3 install "paddleocr>=2.0.1"

3. 运行cmd 命令还会继续安装依赖包
paddleocr --image_dir ./imgs/11.jpg --use_angle_cls true --use_gpu false
# --image_dir 指定图片路径
# --use_angle_cls true设置使用方向分类器识别180度旋转文字
# --use_gpu false设置不使用GPU


n3450 不支持 avx特性，所以 搞不了 paddleocr 一直报错
