# java技术栈总结

  • 模板引擎

    • Jsp 为 Servlet 专用，不能单独进行使用。
    • Thymeleaf 为新技术，功能较为强大，但是执行的效率比较低
    • Freemark 轻量级，性能好

  • 分布式文件系统

    • fastDFS 过时了，环境搭建麻烦，官方不更新
    • minIO 支持主流开发语言SDK，性能高，部署自带管理界面，开源社区活跃度高

  • 了解 MySQL 的逻辑架构以及 InnoDB 的架构（内存、物理）

  • 精通数据库索引的实现原理：B+ 树数据结构来源、索引创建原则，优化原则
